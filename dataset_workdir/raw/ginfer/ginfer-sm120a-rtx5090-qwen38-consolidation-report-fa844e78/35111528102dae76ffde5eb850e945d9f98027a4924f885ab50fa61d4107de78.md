# RTX 5090 Qwen3.8 NVFP4+DFlash2 kernel consolidation

## Scope and controls

This is the bounded multi-patch consolidation campaign required after the complete cycle-9
single-mechanism no-win result. It starts from branch HEAD `3a71eb2a`, whose implementation is
source-identical to accepted cycle-8 source `5876e997`. The immutable 28-field cycle-9 ledger has
SHA-256 `7ebe3bfd925b8a32e394c748f2efbba3fed08bd2b9b35e368ff3541c83d39cdb` and is not modified by
this campaign. Consolidation has its own candidate numbering, ledger, report, and ignored raw tree.

The host is an NVIDIA GeForce RTX 5090 (compute capability 12.0, driver 596.49) with a Release
`sm_120a` image built by CUDA 13.3.73. The registered artifact is
`/ai/ginfer/out/qwen3_8_27b_nvfp4_dflash2_q4.ginfer`, 22,515,440,128 bytes. The production boundary
is stochastic DFlash2 learned width 4, adaptive verification through 15, INT8-G64 KV, 131,072-token
capacity, ordinary CUDA Graph execution, 8,192 resident tokens/request, and concurrency eight.

The budget is 24 consolidation packages and the first acceptance closes the cycle. Every package
must pass focused compilation; every affected independent numerical or exact oracle; every affected
public-Op route and seam; two independent paired Program repetitions; the complete C1 through C8
8K matrix plus 129,041/C1; the explicitly registered real-artifact test; matched 999/1,000 public
Engine execution; and short/long `ORCHID=493817; COLOR=COBALT` semantic sentinels. Each Program
repetition independently must improve matched GPU-round latency by at least 1.5%, or improve
published throughput by more than both 3.0 tok/s and the fresh 5.44 tok/s noise while latency also
improves. Accounting must be identical and repetitions are never averaged to cross a gate.

The ceilings multiply the fresh captured serial cost by the current retained-source public-Op gain;

and thermal/clock variation remain package-level interaction risks.

predeclared path removes c9_07 first, then re-ranks only evidence-supported subsets against the

## Package c10_01 declaration

Package `c10_01` combines frozen component rows c9_01, c9_02, c9_06, c9_07, and c9_21 at source
commits `86c0bb6a`, `ff7262cd`, `eea70401`, `d046cd6e`, and `45a098ae`. It changes only
`src/ops/launcher/gqa_attention_decode.cu`, `src/ops/launcher/gqa_attention.h`,
`src/ops/kernel/gqa_attention_decode.cuh`, `src/ops/kernel/gqa_attention_decode_i8.cuh`,
`src/ops/wrapper/gqa_attention.cpp`, `src/ops/linear/fp8/fp8_config.h`,
`src/ops/gdn_input_proj/fp8/fp8_gdn_input_a8.cu`, and
`src/ops/linear_add/fp8/fp8_linear_add_a8.cu`.

The hypothesis is that the five serial, dispatch-disjoint public-Op savings add at the measured
round boundary without changing arithmetic, state, or source-neutral dispatches. C8 should improve;
C1 through C7 and long C1 should be neutral or faster; T6 B4, T4 B1..7, vocabulary T40/T49,
GDN T127/T129, and residual T127/T129 must remain neutral. The package is falsified by any compile
or oracle failure, loss of an affected public-Op win, material seam/matrix regression, either paired
Program repetition failing both frozen arms, changed stochastic accounting, or any registered
artifact/Engine/semantic failure.

### Package c10_01 result

The focused build and all four independent Op oracles passed. Fresh retained-to-candidate production
anchors in microseconds were T6 B8/8192 cold/warm 179.488/176.960 to 177.440/169.952, T4
142.656/139.968 to 140.096/133.536, vocabulary T48 1404.192 to 1299.776, GDN input T128
85.248 to 80.864, and K6144 residual T128 56.288 to 54.560. Every intended route improved and
observed source-neutral changes remained below 2%.

Program rep 1 changed 44.9490 ms / 2,800.65 tok/s to 44.6087 ms / 2,821.82 tok/s. Its 0.7571%
positive latency and +21.17 tok/s clear throughput arm B above the fresh 5.44 tok/s noise. Rep 2
changed 44.8405 ms / 2,807.42 tok/s to 45.1358 ms / 2,789.24 tok/s, regressing 0.6586% and
18.18 tok/s. All four runs retained exact 3,687 drafted, 3,657 accepted, 248 expanded, 125.968
licensed tokens/batch, and accepted-per-position accounting. The non-averaged gate rejects the
package, and restoration commit `005482a7` returns to the retained implementation.

## Package c10_02 declaration

Package `c10_02` combines c9_01/`86c0bb6a`, c9_02/`ff7262cd`, c9_06/`eea70401`, and
c9_21/`45a098ae`; it removes c9_07, the only component that never independently qualified a Program
repetition and the weakest real-boundary component in c10_01. The four remaining serial costs have
a fresh profile-weighted 0.631 ms / 1.41% idealized transfer ceiling. That is below latency arm A
but comfortably capable of throughput arm B, as c10_01 rep 1 demonstrated.

The package changes the same authorities as c10_01 except
`src/ops/linear_add/fp8/fp8_linear_add_a8.cu`. Its hypothesis is that removing the low-confidence
residual schedule eliminates an adverse serial cache/resource interaction while retaining the four
independently demonstrated public-Op wins. C8 should improve; C1 through C7, long C1, T6 B4, T4
B1..7, vocabulary T40/T49, and GDN T127/T129 must remain neutral or faster. The same compile,
oracle, public-Op, paired non-averaged Program, matrix, artifact, Engine, accounting, and semantic
falsifiers remain in force.

Q/K/V/Z FP32 oracles passed. Fresh retained-to-candidate production anchors in microseconds were

138.720/132.896, vocabulary T48 1,404.192 to 1,326.400, and GDN input T128 85.248 to 80.864.

The explicitly relinked registered real-artifact test passed against the exact 22,515,440,128-byte

Package `c10_02` is accepted at retained source `37a7080c`. It is the first bounded consolidation
