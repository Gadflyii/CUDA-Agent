# SM89 agentic kernel campaign: Muse Glimmer and Qwen3.8-27B

Date: 2026-08-21. Host `DESKTOP-DG588BU` under WSL, NVIDIA GeForce RTX 4090, compute
capability 8.9, driver 596.21, Release `sm_89` image, CUDA 13.3. The campaign used the isolated
`perf/agentic-kernels` worktree and finished at
`65b3fff82721a77680a1023a250a16edf28e821b`.

The method is the active [`kernel optimization campaign`](../maintainer/kernel-optimization-campaign.md)
runbook: one measured hypothesis at a time, independent correctness before timing, at most 24
candidates per cycle, first qualifying real-round win closes a cycle, and one complete no-win cycle
stops the target. Raw profiler reports and full logs remain in the ignored WSL worktree under
`profiles/sm89/rtx4090/`; accepted source, tests, benchmarks, result summaries, and terminal
rejection ledgers are committed.

## Muse Glimmer 30B DFlash2

The frozen route used `muse-glimmer-30b/groupwise-int-dflash-q4`, draft width 4, INT8-G64 paged KV,
CUDA 13.3, and native `sm_89`. Public Op matrices and the maintained Muse Program round drove
candidate decisions. The 8K and 128K Engine retrieval fixtures checked coherent model output and
the exact `ORCHID=493817; COLOR=COBALT` result.

Eight changes were accepted:

| Commit | Retained change |
|---|---|
| `709f2343` | enable the existing SM89 Q4 small-T MMA route for T=5..16 |
| `5191a98b` | extend that route through T=24 |
| `4bbec068` | isolate SM89 R32C40/C48 Q4 kernels in their own translation unit |
| `e5334c9b` | use the narrow Muse W8 output-head tile for T=17..48 |
| `cb0e823f` | make the sixth D128/T5 GQA warp staging-only and admit two resident CTAs |
| `b2bdcba6` | enable the maintained BF16 Tensor Core grouped-convolution projection on CC89 |
| `21310f21` | stage two Q4 groups per N19968/K6656/T40 tile |
| `1bcc89a9` | stage two groups in the R32C40 path |

`fd89181f`, `d5c0c2d1`, and `a6f50543` retain the production Program benchmark/profiler boundaries
needed to evaluate those kernels. The final 24-candidate no-win cycle ended at the restorative
commit `6ad9b538`; its source tree is identical to accepted `1bcc89a9` before the Qwen change.

Representative campaign endpoints:

| Boundary | Initial | Final | Change |
|---|---:|---:|---:|
| Muse Program C4, 8K/request, draft4 | 84.3 ms | about 41.7 ms | about -50.5% latency |

final 128K fixture had 129,041 prompt tokens, 1,695.24 prompt tok/s, and 86.42 decode tok/s. Both
retrieved the exact facts coherently. The terminal rejection ledger is
[`2026-08-21-sm89-muse-cycle9-ledger.csv`](2026-08-21-sm89-muse-cycle9-ledger.csv).

## Qwen3.8-27B MTP3

The frozen resident-round route used the registered `qwen3.8-27b/groupwise-int` artifact, MTP3,
INT8 KV, CUDA Graph replay, 8,192 resident tokens/request, and a fixed 131,072-token shared
capacity. Commit `65b3fff8` changes Q4 LinearSwiGLU T=16/24/32 to four K-split warps while retaining
the prior eight-warp route for T<=8. It also retains a real concurrent Program benchmark and a
registered test that compares eight concurrent MTP3 outputs with ordinary greedy Engine output.

Paired median Program round results:

| Concurrency | Before | After | Improvement |
|---:|---:|---:|---:|
| C1 | 23.7169 ms | 23.6312 ms | 0.36% |
| C4 | 51.1890 ms | 48.6861 ms | 4.89% |
| C8 | 66.6010 ms | 61.3867 ms | 7.83% |

The final restored C8 binary measured 61.2834 ms GPU, 61.3629 ms wall, 260.744 aggregate tok/s,
and 100% acceptance for the fixed round fixture. The optimized Q4 SwiGLU share fell from 25.0% to
19.9% of measured round GPU time.

Long-context semantic sentinels passed exact retrieval:

| Fixture | Mode | Prompt tokens | Prompt tok/s | Decode tok/s | Note |
|---|---|---:|---:|---:|---|
| 8K | MTP3 | 7,680 | 2,240.21 | 147.92 | exact retrieval; 17 generated tokens |
| 128K | MTP0 | 130,048 | 1,533.41 | 39.87 | exact retrieval; 17 generated tokens |

MTP3 at the exact 131,072-token boundary was not falsely presented as a performance result. After
weights it required 5,302,744,320 runtime bytes plus the 1 GiB reserve, exceeding the measured
6,202,866,688 free bytes. The capacity-safe MTP0 long-context sentinel was used instead.

The native independent oracle, full SM89 build, focused test matrix, registered concurrent real
test, and both semantic fixtures passed. A following 24-candidate cycle produced no qualifying
real-round win and restored the accepted source. Its ledger is
[`2026-08-21-sm89-qwen-cycle2-ledger.csv`](2026-08-21-sm89-qwen-cycle2-ledger.csv).
